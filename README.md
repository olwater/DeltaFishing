# DeltaFishing — 三角洲行动自动钓鱼助手

Windows 上的 Rust 三角洲自动钓鱼辅助工具：监听系统输出中的咬钩音，并按状态机完成抛竿、刺鱼与收竿。动作仅在配置的游戏窗口位于前台时执行。

> 当前版本面向《三角洲行动》台钓玩法。请先确认你所在地区、游戏平台及游戏规则允许使用此类工具。

## 使用

1. 从 [Releases](../../releases) 下载 `deltafishing.exe`，或使用 Rust 1.98+ 构建：`cargo build --release`。
2. 启动程序并选择实际播放游戏声音的输出设备；默认设备通常即可。
3. 确认游戏进程名，切回游戏窗口，点击“开始钓鱼”。
4. `F8` 暂停/继续，`F9` 停止运行。窗口失去前台时程序会自动暂停动作。

配置保存在 `%LOCALAPPDATA%\DeltaFishing\config.json`，日志可从界面导出。咬钩阈值越高越不容易误触发，但可能漏检；建议先用默认值观察日志中的相似度峰值再调整。

## 原理与限制

程序通过 WASAPI/CPAL 回环读取系统输出，重采样为 8 kHz 单声道，并与内置 `bite.wav` 做归一化互相关。检测结果驱动一个简单状态机：抛竿 → 等待咬钩 → 延迟刺鱼 → 等待收竿 → 重复。

音量、混音、设备切换和游戏更新都会影响匹配效果；“检测到咬钩”只代表发送了鼠标输入，不代表游戏一定判定成功。程序不会读取账号、网络协议或游戏内存。
