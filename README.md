  - 彻底推翻旧版“高频金属叮声”的经验主义误区，与《三角洲行动》真实鱼漂下顿切水声学物理频谱严格对齐；
  - 采用 **4 阶巴特沃斯数字带通滤波器**，0 dB 无损透传 200~1200Hz 核心共鸣区，强力衰减低频电流机械轰鸣与 2500Hz 以上环境高频水花白噪；
  - 截取 **300ms 纯粹瞬态爆发样本** 并结合 **15ms 水涌冲击整流包络**，在嘈杂环境下咬钩峰值相似度由 `0.30` 跃升至 **`0.96+`**，信噪比提升 **5.5 倍**。
- **🎙️ 全新内置「声学标定工坊」(Acoustic Calibration Studio)**：
  - **双端点区间标定 (Span Labeling)**：波形时间线上自由拖拽拉框，支持鼠标手柄毫秒级微调起止点；
  - **智能自动初筛预标注**：录制完成 0.1s 内自动扫描并圈出疑似咬钩与杂音区间；
  - **台钓 / 路亚 双模式独立标签体系**：全面支持抛竿、切水、刺鱼、收线、顿口、挂底等全周期动作分类；
  - **长录音多轮钓鱼自动分切 (Auto Slice Rounds)**：连续钓多竿无需反复启停录音，系统自动分切单竿片段并支持视口缩放平移；
  - **🪱 换饵保护与 ⚠️ 抛竿失败拒收标记**：精准测算角色换饵动画耗时，采集抛竿被拒报错音，为引擎自愈重试提供数据基础；
  - **全切片离线仿真评测看板**：一键跑全量数据集评估召回率与拦截率，**自动学习并推荐全局黄金门限**，一键应用或导出为专属模板。
- **🚀 效率与自愈机制**：
  - **打断双手捧鱼展示动画**：刺鱼后约 1.2 秒自动点按左键跳过慢动作动画，每竿提速约 3~4 秒；
  - **超时 3 $\rightarrow$ 6 切刀切竿重置**：单轮超时未咬钩时自动切近战打断并切回鱼竿，杜绝动作僵死；
  - **换饵检测与抛竿失败自愈**：避免饵耗尽后强行抛竿卡死。

## 🌊 为什么比普通声音识别更准？

普通挂机脚本通常只计算单声道“时域归一化互相关（ZNCC）”。由于归一化会抹平振幅差异，**距离 50 米开外其他玩家咬钩的声音，算出来的相似度同样能高达 80%~90%**，导致频繁空竿；同时高频水花声与远处的枪炮声经常造成严重误触。

DeltaFishing 引入了**立体声三层几何判据体系 + 游戏原生音频聚焦**：

```text
       [ 系统立体声回环音频采集 (WASAPI Loopback) ]
                           │
           ┌───────────────┴───────────────┐
           ▼                               ▼
    [ 左声道 Left ]                 [ 右声道 Right ]
           │                               │
           └───────────────┬───────────────┘
                           ▼
     [ 4 阶 Butterworth 200~1200Hz 真实切水带通滤波 ]
                           │
 ┌─────────────────────────┼─────────────────────────┐
 ▼                         ▼                         ▼
【判据 1: 存在判据】       【判据 2: 距离判据】       【判据 3: 方位判据】
 瞬态波形 + 包络双通道      全频段瞬态电平卡窗         左右声道声像偏离差
 ZNCC 相似度 ≥ 60%          [-28 dBFS, -6 dBFS]       |Pan dB| ≤ 5.0 dB
 (确认刚才确实有切水声)    (过滤远处弱音与贴脸爆炸)   (正对准星浮漂，滤除侧旁人)
 └─────────────────────────┬─────────────────────────┘
                           ▼
                【全部满足 ➔ 判定咬钩】
                           │
                 (松开右键，触发左键刺鱼)
```

| 判据维度 | 解决的核心痛点 | 算法判定逻辑 |
| :--- | :--- | :--- |
| **存在判据（相似度）** | 刚才到底有没有发生咬钩切水 | 经 200~1200Hz 带通后，与 300ms 核心瞬态模板进行时域波形与包络双通道 ZNCC 匹配（默认 $\ge 60\%$） |
| **归属判据 · 电平 (dBFS)** | 声音是不是来自于自己跟前（距离） | 咬钩瞬态电平必须落在 `[-28 dBFS, -6 dBFS]` 物理安全窗；远方玩家声音太微弱被拦，贴脸枪炮与手雷过响被拦截 |
| **归属判据 · 声像差 (Pan dB)** | 声音是不是来自于正前方准星（方位） | 左右声道电平差 $\le 5\text{ dB}$；自己的鱼漂固定位于正前方，左右声道高度平衡；侧方其他玩家的声音因声像严重偏向单侧被即刻拦截 |
| **游戏原生右键聚焦** | 压制环境大自然杂音与其他玩家声音 | 抛竿入水后自动按住鼠标右键（开镜/缩放聚焦），充分利用游戏音频引擎内置的定向衰减主动压制环境杂音；检测到咬钩瞬间松开右键立即刺鱼 |

## 🎙️ 声学标定工坊 (Studio) 使用指南

如果你在特殊水域、不同音量或极端嘈杂的战区垂钓，可以使用内置的 **声学标定工坊** 进行专属声学微调与数据闭环：

1. **录制实战音频**：
   - 打开软件，切换至顶部的 **`[ 🎙️ 声学标定工坊 ]`** 标签页；
   - 切换 **台钓** 或 **路亚** 模式；
   - 切回游戏水边，挂上鱼饵，点击工坊内的 **【● 开始实机录音】**；
   - 连续正常垂钓 1~3 竿（录制 30~90 秒），随后点击 **【■ 停止录音】**。
2. **多轮自动切片与单竿聚焦**：
   - 系统会自动识别抛竿与收竿动作，将长录音切分为 `第 1 竿`、`第 2 竿` 等独立片段；
   - 点击切片胶囊即可平滑聚焦放大到该竿的波形视野，也可通过下方滑块自由缩放平移。
3. **双端点区间标定与智能预标**：
   - 录音结束时，算法已自动将疑似咬钩和他人杂音打上 `🤖` 预标注；
   - 在时间线上直接用鼠标**按住左键拖拽拉框**选择任意发声区间；
   - 点击打标工具箱中对应的事件按钮（如 `[⚡ 咬钩切水]`、`[🪱 换饵/上饵]`、`[⚠️ 抛竿失败]`、`[💥 干扰杂音]`）；
   - 在波形上拖动标记两端的白色手柄，或在列表中点击 `[◀]` / `[▶]` 即可按 20ms 微调起止边界，点击 `[▶ 播放]` 可实时试听确认。
4. **全切片离线仿真与黄金门限一键应用**：
   - 标定好若干个咬钩与杂音区间后，点击 **【🔍 全切片联合仿真跑分】**；
   - 系统会在几毫秒内离线回放所有数据，给出召回率与拦截率，并**自动计算出当前声音环境下的推荐黄金门限**；
   - 点击 **【一键应用到设置】** 即可让主程序完美适配当前水域；选中优质咬钩片段点击 **【★ 设为模板】** 可导出为专属识别模板！

## 🚀 快速上手

### 1. 下载与运行
- 从 [GitHub Releases](../../releases) 下载最新的 `deltafishing.exe`；
- **由于三角洲行动反作弊系统（ACE）以管理员权限运行，程序已内嵌管理员权限清单，双击启动时请允许 UAC 提权**（确保鼠标输入不受 UIPI 隔离）。

### 2. 操作流程
1. 启动 `deltafishing.exe`，在主界面确认音频输出设备（通常选择包含游戏声音的默认扬声器/耳机即可）；
2. 确认游戏进程名（默认为 `DeltaForceClient-Win64-Shipping.exe`）；
3. 切回游戏窗口，手持鱼竿对准水面；
4. 点击界面上的 **【开始钓鱼】**，或直接按下快捷键 **`F8`**（启动/暂停运行）；
5. 如需紧急终止，按下快捷键 **`F9`**（停止运行）。

> 💡 **提示**：当游戏窗口失去前台焦点（如 Alt+Tab 切出）时，程序会自动挂起所有鼠标与按键操作，绝不在后台乱点。

## ⚙️ 关键参数调节说明（右上角设置页）

| 参数项 | 默认值 | 推荐调节场景 |
| :--- | :--- | :--- |
| **咬钩相似度** | `60%` | 综合匹配度门限。嘈杂场景可提至 `65%~75%`；安静水域若偶尔漏鱼可微降至 `50%~55%` |
| **最小电平** | `-28.0 dBFS` | 距离下限过滤。自身咬钩偶有漏判可放宽至 `-32 dB`；若周围有其他玩家容易被带偏可收紧至 `-25 dB` |
| **最大声像偏离** | `5.0 dB` | 方位正对度限制。数值越小越严格要求声源正对准星。极力推荐保持 `4.0 ~ 5.0 dB` |
| **右键缩放聚焦** | `开启` | 抛竿入水后自动按住右键，利用游戏原生音频引擎压制环境杂音，强烈建议常开 |
| **打断收鱼动画** | `开启` | 刺鱼后约 1.2 秒自动轻点左键跳过慢动作捧鱼结算，大幅提升每小时钓鱼竿数 |
| **超时切刀重置** | `开启` | 抛竿后若超时（默认 28 秒）未咬钩，自动按 `3` 切刀打断并按 `6` 切回鱼竿恢复就绪 |
| **抛竿按键延迟** | `0.4 s` | 模拟真实左键轻点抛竿时长 |
| **收竿等待区间** | `3.5 ~ 4.5 s` | 刺鱼至下次可抛竿之间的安全缓冲时间 |

所有配置自动持久化保存于 `%LOCALAPPDATA%\DeltaFishing\config.json`。

## 🗺️ 技术路线规划 (Roadmap)

DeltaFishing 拥有清晰、严谨的音频信号处理与机器学习演进路线：

- **阶段一（v0.2.0 已完成）**：200~1200Hz 4阶巴特沃斯物理带通滤波、300ms 瞬态提取、立体声空间几何判据、声学标定工坊 (Studio) 全流程数据闭环；
- **阶段二（近期规划）**：GCC-PHAT 频域广义互相关（相位变换抗湍流抖动与混响）、CFAR 恒虚警率动态自适应环境门限、高低频能量比门控（硬件级旁路枪炮噪音）、多环境正交模板聚类融合；
- **阶段三（中期规划）**：短时 Log-Mel 频谱与 MFCC 音色指纹余弦相似度匹配、超轻量 ~50KB 离线 1D-CNN / Micro-YAMNet 神经网络微模型（Rust 端单次 CPU 推理 < 0.5ms，枪林弹雨下达成 99%+ 识别率）；
- **阶段四（远期规划）**：路亚全流程声学闭环状态机、挂底卡障识别与抖竿脱困、高拟人化微扰动输入防检测。
